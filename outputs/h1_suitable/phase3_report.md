# H1 재검증 Phase 3 보고서: 배치 차이의 득점 가치 (KBO vs MLB, 2021~2025)

- 생성 스크립트: `src/h1_suitable/05_run_value.py` (엔진: `src/leadoff/lineup_sim.py`)
- 설계: `config.py` Phase 3 블록(2026-10-04 사전 등록, 커밋 332631e). 시뮬레이션은 MLB 기록 보충 후 데이터로만 실행했다(커밋 88c209d)
- 표본: 주 = primary N=3 팀-시즌(KBO 44, MLB 114), 보조 = 전체(KBO 50, MLB 150). 주전 9인을 구성하지 못해 빠진 팀-시즌은 없다
- 시뮬레이션: 평가 120,000경기, 실제 타순과 반사실 타순에 같은 평가 시드를 쓴다(대응 난수). B는 선택용 8,000경기 시드로 고른 뒤 독립 평가 시드로 다시 평가한다
- 값: ΔR/144 = (반사실 R/G − 실제 R/G) × 144, 팀-시즌 동일 가중 평균. [ts]는 팀-시즌 부트스트랩 95% CI, [cl]은 팀(프랜차이즈) 클러스터 부트스트랩 95% CI, wild p는 팀 클러스터 wild bootstrap p값
- C(9인 전체 재배열)는 이번 실행에 넣지 않았다(§5)

## 1. 요약

- **크기:** 어떤 반사실에서도 이득은 시즌당 약 1점 이하다. 10점이 약 1승이므로 0.1승 미만이다.
- **A (주 결과, wRC+ 1위 주전 ↔ 실제 2번 주전 교환):** KBO +0.22점 [−0.32, +0.75]로 0과 구분되지 않는다. MLB는 +0.73점 [+0.40, +1.11]이다. 리그 차이는 −0.51점 [−1.17, +0.12], wild p=0.09로 경계선이다.
- **B (상위 3명 중 1~2번 최적 교환):** 두 리그 모두 약 +0.9점이고 리그 차이는 −0.08점 [−0.80, +0.78]로 없다.
- **해석:** Phase 2에서 확인한 배치 차이(KBO가 상위 타자를 1~2번에 덜 쓴다)는 실재한다. 하지만 득점으로 환산한 "낭비"는 작다. 이전 분석의 "최고타자 2번 이동: KBO −0.2점, MLB +0.5점"과 크기·방향이 같다.

## 4. 해석

1. **사전 등록한 경고대로 결론은 크기다.** 1위 타자를 2번으로 옮기는 단순 교정의 가치는 KBO 약 0.2점, MLB 약 0.7점(시즌당)이다. 상위 3명 안에서 1~2번을 최적으로 고르는 교정도 약 0.9점이다.
2. **리그 차이(A)는 통계적으로 경계선이고 실질적으로 작다.** 차이는 0.5~0.6점이다. 주 표본에서 wild p=0.09, 보조 표본에서 p=0.04이다. A'를 포함하면 4개 비교 중 3개가 p<0.05이다. 그래도 방향은 "MLB에서 2번 교환의 가치가 조금 더 크다"이다. KBO가 더 많이 잃는다는 뜻이 아니다. KBO는 1위 타자가 이미 대표 타순 2번인 경우가 많고(30% vs 18%), 그렇지 않은 팀에서도 교환 이득이 작다.
3. **B에서 리그 차이가 사라진다.** 상위 3명 중 누구를 1~2번에 둘지 고르게 하면 두 리그의 개선 여지가 같다. KBO의 배치가 MLB보다 득점 면에서 더 비효율적이라는 증거는 없다.
4. **H1 관점:** Phase 1(공급)·Phase 2(유형 매칭)에 이어 Phase 3에서도 "KBO가 강한 2번을 덜 써서 의미 있는 득점을 잃는다"는 주장은 지지되지 않는다. 배치 관행의 차이는 있지만 비용은 시즌당 1점 이하다.

## 5. 한계

- **C(전체 재배열) 미실행:** 사전 등록에서 범위를 "시험 실행 후 결정"으로 남겼다. 이번 결과는 1~2번 교환에 한정된다. 이전 분석의 전체 최적화 이득(KBO +3.0점, 상황확률 엔진)은 9인 전체를 재배열한 값이라 직접 비교할 수 없다.
- **대표 타순 근사:** 실제 시즌에는 매일 타순이 바뀐다. PA가중 평균 슬롯으로 만든 하나의 고정 타순은 그 변동을 반영하지 않는다.
- **선수 성적 고정:** 반사실에서도 선수의 이벤트 확률은 같다고 가정한다. 타순에 따른 승부 방식 변화나 타석 상황에 따른 성적 차이는 모형에 없다.
- **엔진:** 기본 엔진은 두 리그 모두 R/G를 약 3% 과대 추정한다. MLB용 상황확률표가 없어 리그 비교는 기본 엔진으로만 했다. 기본 엔진에는 희생번트·선수별 도루/병살 성향이 없다.
- **KBO 표본:** KBO는 44(주)/50(보조) 팀-시즌, 10개 프랜차이즈라 클러스터 기반 CI와 p값이 불안정할 수 있다.
- **다중 비교:** 반사실 3개 × 표본 2개를 보정하지 않았다. 주 결과는 사전 등록한 A·N=3·기본 엔진 하나다.
